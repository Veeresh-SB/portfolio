# Veeresh Bhankapure — Portfolio

## Run locally
1. Open this folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html` and choose **Open with Live Server**.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your public `portfolio` repository.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Your site should be available at `https://Veeresh-SB.github.io/portfolio/` after deployment.

## Files
- `index.html`: page content
- `style.css`: design and responsive layout
- `script.js`: rotating title and public GitHub repositories
- `resume.pdf`: resume supplied for this portfolio

The portfolio content is based on the provided resume. Add links to project repositories once they are available.
